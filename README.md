# Login System Implementation – Flask & Django

## Project Overview

This repository contains two separate branches demonstrating the implementation of a user authentication system using two popular Python web frameworks:

- Flask  
- Django  

Both implementations:

- Use SQLite3 for database management  
- Store hashed passwords securely  
- Authenticate users via a login system  
- Display a random image upon successful login  

The goal of this project is to understand authentication workflows and compare how Flask and Django handle user management and database interaction.

---

## Branch 1: Flask Implementation

### Features

- User authentication using Flask  
- SQLite3 database integration  
- Secure password hashing before storage  
- Session management for logged-in users  
- Random image display after successful login  
- User registration and login system  

### Learning Outcomes

- Understanding Flask application structure  
- Implementing authentication and session management manually  
- Integrating SQLite with Flask  
- Applying password hashing for secure storage  
- Rendering dynamic content based on login state  

---

## Branch 2: Django Implementation

### Features

- User authentication using Django’s built-in authentication system  
- SQLite3 database integration  
- Automatic password hashing via Django ORM  
- User registration and login  
- Random image display after successful login  

### Learning Outcomes

- Understanding Django project structure  
- Using Django’s built-in authentication system  
- Working with Django ORM and SQLite  
- Managing database migrations  
- Implementing dynamic content rendering  

---

## Common Features Across Both Branches

- User Registration  
- User Login Authentication  
- Secure Password Hashing  
- SQLite3 Database Integration  
- Random Image Display After Login  
- Basic Session Handling  

---

## Comparative Learning Value

This project allows learners to:

- Compare lightweight framework architecture (Flask) with full-stack framework architecture (Django)  
- Understand manual vs built-in authentication handling  
- Practice database interaction in two different ecosystems  
- Strengthen backend development fundamentals  

---

## Conclusion

This project serves as a practical comparison between Flask and Django for implementing a secure login system. By building the same application in both frameworks, learners gain deeper insight into authentication mechanisms, database management, and dynamic content rendering in modern web development.
